# 🌐 Pratik Bothra — Personal Portfolio

This repository contains the source code for my personal portfolio website, built to showcase my projects, skills, and overall journey as a developer.

🔗 **Live Website:** https://pratikbothra.vercel.app/

---

## ✨ Features

- ⚡ Built with **React + Vite** for fast development
- 🎨 Styled using **TailwindCSS**
- 🌗 **Dark / Light mode** with system preference support
- 🧭 **Scroll spy navbar** with active section highlight
- 📱 Fully **responsive & mobile-friendly**
- 🎬 Smooth animations using **Framer Motion**
- 🗂️ Projects section with clean UI and details
- 📝 Blog / Notes section
- 📄 Resume accessible from the navbar
- 🚀 Deployed on **Vercel**
- 💬 Floating “Let’s Talk” quick contact button

---

## 🛠️ Tech Stack

- **Frontend:** React, Vite
- **Styling:** TailwindCSS
- **Animations:** Framer Motion
- **Icons:** React Icons
- **Deployment:** Vercel
